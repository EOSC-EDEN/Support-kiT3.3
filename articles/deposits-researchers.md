### Considerations

Key aspects to consider include:
- Did you review the data you plan to deposit (e.g. are all necessary files included/unnecessary or redundant files removed? Which are raw, processed, derived, or final data?)  
- Are the file formats appropriate (e.g. widely used and supported, non-proprietary if possible)?
- Is technical file quality (e.g. files open correctly, completeness, coherent and clear file names) ok?
- Is the data machine-readable (e.g. consistent data types, consistent representations of missing values,  include units of measurement)?
- Did you use documented standards and conventions (e.g. units, geographic coordinates and reference systems, variable names and identifiers) commonly used in your scientific discipline?
- Is the data internally consistent (e.g. consistent variable names)?
- Is the data sufficiently and clearly explained and documented (e.g. readme file)?
Did you include provenance and processing information (e.g. processing scripts/documentation)?
Does the metadata reflect the actual files?


### Recommendations

- Check and follow the deposit guidelines of the repository you chose for your data deposit
- Familiarise yourself with (meta)data standards as well as conventions within your discipline and use them consistently
- Think about future re-use: does the dataset contain all necessary information by someone else?
