This path is for you if you are a researcher, PhD candidate or principal investigator who produces data and deposits it with a repository.

**Your focus:** Preparing data so that it can be deposited, preserved and reused: choosing sustainable formats, documenting files, and checking them before you hand them over.

The modules below are listed in a suggested order. Start with the first, or jump to the task you're working on now.
