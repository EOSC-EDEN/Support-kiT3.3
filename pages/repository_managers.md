This path is for you if you are a repository manager, archivist or curator who runs a data repository or preservation service.

**Your focus:** Running the processes that keep deposited data trustworthy: reviewing deposits, managing identifiers and metadata, monitoring risks, and demonstrating trustworthiness through certification.
