You write in Google Docs, as you normally would. You don't need a GitHub account, Markdown or any scripts.

1. Make a copy of the [module template](https://docs.google.com/document/d/16JsiG9edwKCt3cuaTMEdR3kISEdrFYqT3MPK489iLys/edit) (File › Make a copy). The [worked example](https://docs.google.com/document/d/1FBlwyqkM-S8QlRBxH58q8z9H-2KLo3ufBdt3yJwDeEc/edit) shows one filled in.
2. Fill in the table, using the dropdowns where there are some, and write the module. Share it with colleagues for comments as usual.
3. When it is ready, move the Doc into the folder [EDEN Support-kit – ready for the kit](https://drive.google.com/drive/folders/1qTIuQq-G62Bf6-CZgTxH-C4KevIcWnGI).

Within the hour you get a comment in your Doc with a link to the review. Keep editing the Doc and the review updates. The walkthrough below shows each step and what you will see.

## Prefer to work in GitHub?

Every page has **Edit** and **Open an issue** buttons. Module pages are Markdown files under `pages/<role>/`, and the metadata fields are described in the repository's README. Pull requests are welcome.
